# 🎯 맞사속상영 — 실시간 상식 퀴즈 배틀

**맞**춤법 · **사**자성어 · **속**담 · **상**식 · **영**단어

수업 시작 전, 남는 시간, 학급 활동 시간 등 언제든 반 전체가 휴대폰으로 함께 겨루는 실시간 퀴즈 웹앱입니다.

- **카테고리 5종**: 맞춤법(보기 2개) · 사자성어(초성 힌트 주관식) · 속담(빈칸 주관식) · 상식(O/X) · 영단어(보기 4개)
- **수준 2단계**: 중학생 / 고등학생 — 카테고리·수준별로 100문항 이상 수록
- **이어서 출제**: 학급마다 카테고리·수준별로 어디까지 풀었는지 기억하고, 끝까지 풀면 1번부터 다시
- **진행**: 문제 읽기 10초 → 답하기 10초 (건너뛰기 가능, 모두 답하면 자동으로 넘어감)
- **점수**: 정답이면 500점 + 빨리 맞힐수록 최대 500점 추가 (최대 1000점)
- **결과 화면**: 정답·오답·미응답 인원, 선택지별 인원(객관식) / 오답 구름(주관식), 교사용 개인별 응답표
- **최종 순위**: 1·2·3등 시상대 + 나머지는 작게

---

## 1단계. 먼저 체험해 보기 (설치 없이)

`config.js`가 비어 있으면 **데모 모드**로 동작해요. 같은 브라우저 안의 탭끼리만 연결됩니다.

1. GitHub Pages에 올리거나(3단계), 로컬에서 열어 보세요.
2. 탭 하나에서 **선생님 → 새 학급 만들기**
3. 다른 탭에서 `주소?c=학급코드` 를 열어 학생으로 입장

> 실제 수업(학생 각자 휴대폰)에서 쓰려면 아래 2단계 Firebase 설정이 꼭 필요해요.

---

## 2단계. Firebase 실시간 DB 만들기 (무료, 약 10분)

1. <https://console.firebase.google.com> 에 구글 계정으로 로그인 → **프로젝트 추가**
   - 이름 예: `matyeora` · Google 애널리틱스는 꺼도 됩니다.
2. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기**
   - 위치: **싱가포르(asia-southeast1)** (한국에서 가장 빠름)
   - 보안 규칙: **잠금 모드로 시작**
3. 생성 후 **규칙** 탭에서 아래 내용으로 바꾸고 **게시**

   ```json
   {
     "rules": {
       "rooms": {
         "$code": {
           ".read": true,
           ".write": true,
           ".validate": "$code.matches(/^[0-9]{8}$/)"
         }
       },
       "phrases": {
         "$h": { ".read": true, ".write": "!data.exists()" }
       }
     }
   }
   ```

4. 톱니바퀴 **프로젝트 설정 → 일반 → 내 앱 → 웹(</>)** 아이콘 → 앱 이름 입력 → 등록
5. 화면에 나온 `firebaseConfig` 값들을 **`config.js`** 에 그대로 붙여 넣기

   ```js
   window.FIREBASE_CONFIG = {
     apiKey: "AIza....",
     authDomain: "matyeora-xxxx.firebaseapp.com",
     databaseURL: "https://matyeora-xxxx-default-rtdb.asia-southeast1.firebasedatabase.app",
     projectId: "matyeora-xxxx",
     ...
   };
   ```
   ⚠️ `databaseURL` 이 꼭 있어야 해요. 없으면 Realtime Database 화면 맨 위의 주소(https://…firebasedatabase.app)를 복사해 넣으세요.

무료(Spark) 요금제로 동시 접속 100명까지 충분합니다. 한 반 30명 기준으로 비용이 생길 일은 사실상 없어요.

---

## 3단계. GitHub Pages로 배포

1. GitHub에서 새 저장소 만들기 (이름이 짧을수록 학생 주소도 짧아져요. 예: `quiz`)
2. 이 폴더의 파일을 **폴더 구조 그대로** 업로드 (`questions` 폴더 포함)
3. **Settings → Pages → Branch: main / (root) → Save**
4. 1~2분 뒤 `https://아이디.github.io/quiz/` 로 접속

학생 주소는 대기실 화면에 QR과 함께 자동으로 표시됩니다.

## 사용법

**선생님**
1. 첫 화면 → **선생님** → **새 학급 만들기**
   - *찾기 문구*(예: `종암2026202`)와 비밀번호를 정하면 8자리 학급 코드가 생겨요.
   - 다음부터는 찾기 문구(또는 학급 코드) + 비밀번호로 입장
2. 카테고리 · 수준 · 문제 수 선택 → **대기실 열기**
3. TV 화면의 QR/주소로 학생 입장 → 이름이 뜨면 **시작하기**
   - 잘못 들어온 이름은 눌러서 내보낼 수 있어요.
4. 문제마다 결과 화면에서 **다음 문제 ▶**, 마지막엔 **최종 순위**
   - `🔒 개인별 응답 보기` 는 학생 화면에는 나오지 않아요(교사 화면에서만 열림). 화면 공유 중이라면 TV 연결을 잠깐 끄고 여세요.
5. **📝 문제 보기·수정**에서 문제를 고치거나, `이 문제부터 출제`로 다음 출제 번호를 바꿀 수 있어요. 수정은 그 학급에만 적용됩니다.

**학생**: QR 촬영 → (코드 자동 입력) → 본명 입력 → 대기. 새로고침해도 같은 이름으로 다시 들어오면 점수가 이어집니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 틀 |
| `style.css` | 디자인 |
| `app.js` | 교사·학생·진행 기능 전체 |
| `db.js` | Firebase / 데모 모드 연결 |
| `config.js` | **Firebase 설정값 (직접 입력)** |
| `questions/*.js` | 기본 문제 은행 (카테고리별) |

기본 문제를 학교 전체에 맞게 바꾸고 싶으면 `questions/` 파일을 직접 고치면 됩니다. 각 파일 맨 위에 형식이 적혀 있어요.

시간을 바꾸려면 `app.js` 맨 위의 `SHOW_MS`(읽기), `ANSWER_MS`(답하기) 값을 밀리초로 고치세요.

## 알아 두면 좋은 점

- 교사 비밀번호는 학생이 교사 화면에 들어오는 것을 막는 수준의 잠금이에요. 성적·개인정보처럼 민감한 내용은 저장하지 않도록 설계했고, 학생 이름과 점수만 저장됩니다.
- 진행 중에 교사 화면을 새로고침하면 그 판은 종료돼요(점수 진행 위치는 저장됨).
